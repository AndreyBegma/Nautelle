# Nautelle v0.17.0

Released 2026-10-24 · Runner: 0.17.0, released with this version (`runner-v0.17.0`, cut from the same `main` commit) ·
Changelog entry: `packages/shared/src/changelog.ts`

## Summary

Trying Nautelle is now a single command:

```sh
docker run -p 8000:8000 -v nautelle:/data abegma/nautelle
```

That all-in-one image runs the API, the web app and the proxy together. Without a database URL it starts in demo mode with an embedded PostgreSQL and Redis. It is not for production; use the compose install or the Helm chart there. Every release is now published on Docker Hub as well as on ghcr.io, with the same digests and signatures.

Demo videos of several cards now record at the same time.

**Upgrade:**
- Update every runner to 0.17.0.
- A project's `demoflow.config.json` should write `${PORT}` where the port goes, for example `"baseUrl": "http://127.0.0.1:${PORT:-3000}"`. A fixed port records one demo at a time.

## What changed

### New

- You can try Nautelle with one docker run of an all-in-one image, and every release is also published on Docker Hub.

### Improved

- Demo videos of several cards record at the same time, each on a port of its own.

### Fixed

- The daily AI digest goes out at the time you set on the day the clocks change.
