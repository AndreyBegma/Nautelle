# Nautelle v0.18.0

Released 2026-10-26 · Runner: 0.18.0, released with this version (`runner-v0.18.0`, cut from the same `main` commit) ·
Changelog entry: `packages/shared/src/changelog.ts`

## Summary

This release finishes the 2026-10-25 core plan: speed, daily flow, fleet scale and team. The Board loads fast and updates live. Everything that waits on you sits on one Inbox page. The fleet queues cards at its worker limit and pauses at a hard budget instead of failing. Teams get email and Slack notifications, personal API tokens and account recovery without the command line.

**Upgrade:**
- Update every runner to 0.18.0. Card demo videos need it: their scenarios now sign in off camera, which the DemoFlow version bundled with runner 0.17 rejects.
- Thirteen database migrations run on deploy (listed in the release pull request).
- Email is optional: set `SMTP_URL` and `SMTP_FROM` in the API environment to send notification emails and to offer Forgot password on the sign-in page. Without them, the sign-in page tells people to ask an admin.

## What changed

### New

- An admin can give a locked-out person a one-time link to reset their password or two-factor sign-in, and with email set up people reset their own password from the sign-in page.
- Notifications can go out by email, at once or gathered into a digest, and to a Slack channel through an incoming webhook.
- Personal API tokens act with your rights or read-only, can be limited to some projects, expire and can be revoked at any time.
- An Inbox page gathers everything that waits on you across projects with its action at hand, and Away mode can allow similar requests for a whole session or project.
- At the worker limit cards wait and start in To Do order, a hard budget pauses running rounds until you resume them in one click, and a project can move to another runner.

### Improved

- The Board loads fast, updates live, moves merged cards to Completed by itself, and the command palette finds cards and runs actions from the keyboard.
- Onboarding walks you to your first card with a repository picker, a quick card turns one line of text into a To Do card, and project settings can be searched.

### Fixed

- Questions with several tabs reach you in full, and card demo videos open already signed in without leaving stray changes in the pull request.

## Runner

[runner-v0.18.0](https://github.com/AndreyBegma/Nautelle/releases/tag/runner-v0.18.0) ships with this release, cut from the same `main` commit. It pins DemoFlow 0.7.0 so demos sign in off camera, lists repositories when you connect a project and checks push access, prefers an active `develop` as the base, stops demos from leaving files behind, and carries the runner side of Away mode's similar-request rules and of multi-tab question forms. Its notes are in [`apps/runner/CHANGELOG.md`](../../apps/runner/CHANGELOG.md#0180). Nothing is held for a later runner release.
