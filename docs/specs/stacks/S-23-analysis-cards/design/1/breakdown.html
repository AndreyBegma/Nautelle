  1. 1

    Board tileChanged

    An analysis card shows an "Analysis" kind tag with a scan icon and a count of its proposals. It has no demo chip or checks badge, because no pull request comes out of it. While the report waits for selection the pill reads "Waiting on you", so the card shows up in the same triage as approvals.

    Badge · StatusPill · board-card

  2. 2

    Sheet headerChanged

    The existing card sheet, widened to 720 px so the report reads well. The Read-only badge is a fact, not a status, so it is a neutral Badge with a lock. It says the runner enforces read-only (ADR-0126), not just the prompt. There is no solid action up here; the only one is in zone 7.

    Sheet · Badge · StatusPill · Tabs

  3. 3

    Run factsNew

    This replaces the branch and PR key/value pairs an analysis card does not have. It shows what was read, how many rounds ran, how long, and what it cost. On mobile it folds into two columns.

    KeyValueList (grid variant) · .num

  4. 4

    ReportNew

    The markdown from finish_analysis, rendered with react-markdown and remark-gfm. It is collapsed to about 280 px with a fade and "Show full report". Copy puts the raw markdown on the clipboard. Findings are anchors, so proposals can point at them.

    Section · surface-content · react-markdown · Button ghost sm

  5. 5

    Proposed cardsNew

    A flush row list with one Checkbox per proposal and a select-all header with a live count. Every proposal starts ticked, and the person unticks what is not worth doing. A created proposal turns into a link to its card and can't be ticked again.

    Section flush · Checkbox · row list

  6. 6

    Proposal metaNew

    The kind (Bug, Feature or Task) is a neutral tag with an icon, because kind tells cards apart and is not a status. Target paths are in mono and labels are small tags. "From finding N" scrolls the report to its evidence. The Task kind is created only once the task kind exists. Labels are applied only once S-21 card labels land; until then they show as tags but are not applied.

    Badge · Chip (static) · link

  7. 7

    Create selectedNew

    A sticky footer holds the sheet's one solid action, with the count in its label; it is disabled at zero. "Land in" picks To Do or Inbox. Creating is reversible (the cards can be archived), so there is no ConfirmDialog. Each card is linked back to C-512, and C-512 then moves itself to Done. A failure goes to useErrorToast and keeps the selection.

    SegmentedControl sm · Button solid · toast
