Take a backup first. Downgrading is not supported. A backup is the way back. Back up an install
  1. 1Docker Compose Usual way

    Run in the nautelle directory on the server. The API applies migrations when it starts.

    docker compose pull
docker compose up -d
  2. 2Re-run install.sh

    Fetches the current compose file and keeps .env and its passwords.

    curl -fsSL https://raw.githubusercontent.com/AndreyBegma/Nautelle/main/deploy/compose/install.sh | sh
  3. 3Pinned to a version

    If nautelle/.env pins NAUTELLE_VERSION, change it to this line, then run docker compose up -d.

    NAUTELLE_VERSION=0.18.0

Run these on the server. Nautelle cannot restart its own stack from the web app. Runners are upgraded separately, on their own machines; Admin › Runners lists them.
