# C-519: Docs site — notifications: in-app, Telegram, email and Slack

Stack **S-21 "Docs match the product"**, stage 1 (after C-515 creates the **Using Nautelle** group). Part of the
2026-10-26 improvement plan.

## Summary
Nautelle notifies on four channels, but the docs site only lists the environment variables. Write one page that
says what gets notified, where, and how a person and an admin set each channel up.

## Scope
**In:** `apps/docs/src/content/docs/using/notifications.md` (frontmatter `sidebar.order: 2`).
**Out:** `astro.config.mjs` (the group autogenerates), `configuration/environment.md` (generated by `docs:env`),
app code.

## Current state
- [Confirmed] A notification is written once and delivered on channels; Telegram and email are per-person channels
  with rules and mutes; folded notifications are not re-sent (ADR-0108 §1).
- [Confirmed] Email is configured by `SMTP_URL` and `SMTP_FROM` only, never stored; without `SMTP_URL` email is off
  and the Email column is hidden (ADR-0108 §2; `apps/docs/src/content/docs/configuration/environment.md:50-51`).
  A person's email settings: `apps/web/src/app/account/notifications/email-card.tsx`.
- [Confirmed] Slack: one incoming webhook per project (Settings › Slack) and one for the workspace (Admin ›
  Integrations › Slack); a project's replaces the workspace one; per-event toggles `finished`, `demo`, `question`,
  `failed`, `budget`, `merged`; the URL is sealed with `APP_ENCRYPTION_KEY` and shown by its last four characters;
  no mutes or folding (ADR-0109 §1–3, ADR-0108 §1 amendment).
- [Confirmed] Telegram: the bot and Mini App (ADR-0046, ADR-0055); setup in Admin › Integrations › Telegram, a
  person links their chat in Account › Notifications (`apps/web/src/app/account/notifications/telegram-card.tsx`).
- [Confirmed] Per-kind rules and mutes: `rules-section.tsx`, `mutes-section.tsx` in the same folder.

## What
Sections: **What you are notified about** (the kinds, from `NOTIFICATION_KIND_SPECS` in `packages/shared`) ·
**In the app** (the bell, the Inbox link) · **Telegram** · **Email** · **Slack** · **Choosing per kind and muting**.
Each channel says who sets it up (admin vs person), where, and what it needs (`APP_ENCRYPTION_KEY`, `APP_URL`,
`SMTP_URL`). Link the environment page instead of repeating variable tables.

- [ ] Each channel's prerequisites match ADR-0108/0109 and the env page; the kinds list matches

- [ ] `bun run check` passes. No app UI change, so no demo.
